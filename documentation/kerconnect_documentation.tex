\section{Presentation du Projet}
% ─────────────────────────────────────────────

\subsection{Vision et Objectif}

KerConnect est une plateforme immobiliere 100\% en ligne concue pour le marche senegalais.
Elle connecte les bailleurs, proprietaires et clients (locataires / acheteurs) dans un
ecosysteme digital securise, de la recherche de bien jusqu'au paiement du loyer ou du
prix d'achat, en passant par la signature electronique du contrat.

\textbf{Probleme resolu :} Le marche immobilier senegalais souffre d'un manque de
transparence, de faux contrats, de litiges recurrents et d'un acces difficile aux
offres fiables.

\textbf{Solution KerConnect :}
\begin{itemize}
  \item Annonces verifiees et validees par un administrateur avant publication
  \item Contrat numerique : upload PDF bailleur $\to$ signature manuscrite client $\to$ validation bailleur
  \item Paiements tracables via Wave, Orange Money, carte ou especes
  \item Commission automatique de la plateforme (taux configurable par l'admin)
  \item Score de confiance et badge ``Verifie'' pour les bailleurs serieux
\end{itemize}

\subsection{Middleware d'Authentification (proxy.ts)}

\begin{lstlisting}[caption=Convention Next.js 16 -- proxy.ts]
export function proxy(request: NextRequest) {
  const isAuthenticated = request.cookies.has('kc_auth')
  // Protege /client/* /bailleur/* /admin/*
  if (isProtectedRoute && !isAuthenticated) {
    return NextResponse.redirect('/auth/login?redirect=' + pathname)
  }
  // Redirige vers dashboard selon role si deja connecte
  if (isAuthRoute && isAuthenticated) {
    const role = request.cookies.get('kc_role')?.value
    return NextResponse.redirect(DASHBOARD[role])
  }
  return NextResponse.next()
}
\end{lstlisting}

\section{Fonctionnalites Innovantes}
% ─────────────────────────────────────────────

\subsection{Commission Automatique}

La plateforme preleve un pourcentage configurable sur chaque paiement confirme.

\begin{center}
\begin{tabular}{|l|r|}
\hline
Loyer mensuel & 200 000 FCFA \\
Commission (5\%) & 10 000 FCFA $\to$ Naratechvision \\
\textbf{Net bailleur} & \textbf{190 000 FCFA} \\
\hline
\end{tabular}
\end{center}

L'admin peut modifier le taux depuis \texttt{/admin/settings} et consulter
le tableau de bord des revenus cumules sur \texttt{/admin/commissions}.

\subsection{Score de Confiance}

Apres validation contrat + paiement confirme, les deux parties se notent
mutuellement de 1 a 5 etoiles avec commentaire. La note moyenne est
affichee sur chaque bien et le badge ``Verifie'' est attribuable par l'admin.

\subsection{Alertes Biens}

Les clients creent des alertes (ville + nature + type + prix max).
Lors de la publication d'un nouveau bien correspondant, une notification
est envoyee automatiquement.

\subsection{Messagerie Integree}

Client et bailleur s'envoient des messages depuis la plateforme via emails
avec \texttt{reply-to} configure pour permettre la reponse directe par email.

\subsection{Rapport Mensuel Bailleur}

La page \texttt{/bailleur/rapport} affiche un rapport filtre par mois/annee :
total brut, commissions, net recu, tableau detaille, export PDF (\texttt{window.print()}).

\subsection{Notifications Temps Reel}

Polling 30 secondes sur \texttt{GET /v1/notifications} :
demandes recues, paiements en attente, contrats signes par le client.

\section{Securite}
% ─────────────────────────────────────────────

\begin{itemize}
  \item \textbf{Tokens :} Sanctum Bearer, TTL 7 jours, revocation a la deconnexion
  \item \textbf{Middleware roles :} \texttt{role:client}, \texttt{role:bailleur}, \texttt{role:admin} sur chaque groupe
  \item \textbf{OTP :} Code 4 chiffres, expiration 15 min, 3 tentatives max
  \item \textbf{Rate limiting :} 5 tentatives login, blocage 60s
  \item \textbf{Paiement bloque :} Backend verifie \texttt{contrat.statut = valide}
  \item \textbf{Uploads :} Validation MIME stricte (PDF/images seulement), max 20 Mo
  \item \textbf{CORS :} Configure via Laravel pour accepter uniquement le domaine frontend
\end{itemize}
